# Omar Abu Kweik — Network & Cybersecurity Portfolio

A responsive, bilingual (English/Arabic) personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Before publishing — personalize these items
- Replace `your.email@example.com` with your real professional email.
- Replace the LinkedIn and GitHub profile URLs with your actual profile URLs.
- Confirm the exact English name of your bachelor's degree as printed on your certificate.
- Add your CV PDF, profile photo (optional), and links/screenshots for completed projects.
- Add evidence or links for certifications if you want recruiters to verify them.
- Update skill descriptions so they accurately reflect your current practical level.

## Files
- `index.html` — page structure and content
- `style.css` — dark navy/cyan responsive design and RTL layout
- `script.js` — Arabic/English language switch and mobile navigation

## Hosting
This is a static website and can be deployed free on GitHub Pages, Netlify or Vercel. No backend is required.
